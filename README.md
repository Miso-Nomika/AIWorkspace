# AIWorkspace

Claude Code와 대화하며 프로젝트를 진행하는 Windows·Linux 데스크톱 앱입니다. 코드를 직접 다루지 않아도 됩니다.
프로젝트 폴더 연결, Claude Code 채팅·승인, 결과 파일 확인, Git 상태, 여러 PC 간 공통 메모리 동기화를 한 화면에서 제공합니다.

## 설치

[Releases](https://github.com/Miso-Nomika/AIWorkspace/releases/latest) 페이지에서 운영체제에 맞는 파일을 내려받습니다.

**Windows** — `AIWorkspace_<버전>_x64-setup.exe`를 실행합니다.
- 관리자 권한 없이 현재 사용자 계정에 설치되며, 바탕화면 바로가기를 만들 수 있습니다.
- WebView2 런타임이 없으면 설치 중 자동으로 설치됩니다(인터넷 필요).
- 첫 실행 시 SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누릅니다.

**Linux** (Ubuntu·Debian) — `AIWorkspace_<버전>_amd64.deb`를 내려받아 `sudo apt install ./AIWorkspace_<버전>_amd64.deb`로 설치합니다.

### 업데이트
새 버전이 나오면 앱 위쪽에 "새 버전 · 지금 업데이트" 버튼이 나타납니다. 누르면 내려받아 설치하고 앱이 다시 시작됩니다(Windows). Linux .deb는 새 버전 안내만 나오므로 새 .deb를 직접 설치하세요. 새 버전 확인은 앱을 켠 직후 한 번만 합니다. 업데이트 기능이 들어간 0.7.0은 한 번 직접 설치해야 합니다.

### 사전 준비

Claude Code CLI가 설치되어 있고 로그인되어 있어야 합니다.

## 사용법

### 처음 실행할 때
**시작 설정** 창에서 Claude Code 설치 상태를 확인하고, Google Drive 동기화 폴더(자동 감지)와 테마를 고릅니다.
다른 PC에서 쓰던 개인 취향(공통 메모리)과 테마가 바로 적용되며, 프로젝트는 PC마다 따로 만듭니다. 나중에 메모리 화면에서 다시 열 수 있습니다.

### 1. 프로젝트 만들기
홈에서 새 프로젝트를 만들고 **새 폴더 만들기** 또는 **기존 폴더 선택** 중 하나를 고릅니다.
프로젝트를 삭제해도 등록만 해제되며 실제 폴더와 파일은 그대로 남습니다.
홈 화면은 왼쪽이 프로젝트 목록, 오른쪽이 **터미널**이며 둘 사이 구분선을 끌어 크기 비율을 조절할 수 있습니다(더블클릭하면 기본 비율, 저장됨)(PowerShell 또는 사용자 셸, 홈 폴더에서 시작). 직접 명령을 칠 수 있고, 다른 화면에 갔다 와도 셸과 이전 출력이 남아 있으며, 복사·붙여넣기는 Ctrl+Shift+C / V입니다.
프로젝트를 열면 폴더에 **TODO.md**(앞으로 할 작업)와 **기능명세서.md**(구현된 기능)가 없을 때만 만들어지고, Claude Code가 작업 후 두 문서를 갱신합니다.

### 원격 PC의 폴더로 작업하기 (선택)

SSH로 접속할 수 있는 다른 PC(Linux·Mac)의 폴더도 같은 방식으로 작업할 수 있습니다. 설정은 앱 안에서만 하면 됩니다.

1. **준비**: 이 PC에서 키로 접속되어야 합니다(비밀번호 로그인은 지원하지 않습니다). 원격 PC에 Claude Code가 없어도 괜찮습니다 — 아래 3번에서 앱이 설치와 로그인을 도와줍니다(원격 PC에 인터넷이 필요합니다).
2. **옵션 → 원격 접속 (SSH) → 원격 PC 추가**: 주소(또는 `~/.ssh/config`의 별칭)·사용자·포트·키 파일 경로를 입력하고 **연결 시험**을 누릅니다. 처음 접속하는 PC는 지문이 나오는데, 맞는 PC일 때만 **신뢰하고 연결**을 누르세요.
   연결 시험 아래에 원격 Claude Code 상태가 나옵니다. 없으면 **원격에 설치**, 설치만 되어 있으면 **로그인**을 누르세요. 로그인은 브라우저가 열리면 Claude 계정으로 승인하고, 승인 뒤 화면에 나온 코드를 앱의 입력칸에 붙여 넣으면 끝납니다(원격 PC에 직접 들어갈 필요가 없습니다).
3. **새 프로젝트 → 원격(SSH)**: 등록한 PC를 고르고, 폴더 선택기에서 프로젝트 폴더를 고릅니다(새 폴더도 만들 수 있습니다).
4. 이후는 이 PC의 프로젝트와 같습니다. (새 프로젝트 화면에서도 같은 설치·로그인 버튼이 나옵니다.) 공통 메모리는 항상 이 PC의 것을 쓰고, 연결이 끊기면 화면 위의 **다시 연결**을 누르면 됩니다. (원격 PC에 `inotify-tools`를 설치하면 원격에서 바뀐 파일이 바로 보입니다.)

### 2. Claude Code와 대화하기
프로젝트 화면의 채팅창에서 작업을 요청합니다.

- 채팅창 위에서 권한을 고릅니다.
  - **변경 전 확인**(기본): 파일 수정·명령 실행 전에 승인 카드가 뜹니다. **허용 / 항상 허용 / 거부** 중 선택합니다.
  - **자동 승인**: 묻지 않고 진행합니다. 질문과 계획 승인만 묻습니다. 작업 도중 "이후 모두 자동 승인"으로 바꿀 수도 있습니다.
- 같은 프로젝트의 대화는 이어서 진행되며, 중지 버튼으로 언제든 실행을 멈출 수 있습니다.
- 입력창은 내용에 맞춰 높이가 늘어납니다 (Enter 전송, Shift+Enter 줄바꿈).
- 왼쪽 탐색기와 가운데 뷰어에서 만들어진 파일을 확인할 수 있습니다(읽기 전용). 폴더는 펼칠 때 안을 읽으므로 파일이 아주 많은 폴더가 있어도 프로젝트 바로 아래의 `TODO.md` 같은 파일이 가려지지 않습니다(한 폴더는 처음부터 이름순으로 최대 50,000개까지 보여 주고, 그보다 많으면 폴더 끝에 안내가 나옵니다). 탐색기의 **변경** 탭에서는 Claude Code가 바꾼 파일 목록과 변경 내용(Git 기준)을 볼 수 있고, **변경** 탭에서 파일을 체크하고 **되돌리기**를 누르면 마지막 커밋 상태로 돌아갑니다(새 파일은 삭제). 파일 트리에서 파일·폴더를 우클릭하면 새로 만들거나 **이름 변경(R)**·**삭제**할 수 있고(파일을 선택하고 **F2**를 눌러도 이름을 바꿀 수 있습니다), 삭제는 휴지통을 거치지 않고 영구적으로 지워집니다. 프로젝트 화면 위쪽 **폴더 열기**로 파일 관리자에서 폴더를 열 수 있습니다. 뷰어 위쪽 줄의 **터미널 아이콘**(뷰어 접기 버튼 옆)을 누르면 뷰어 아래가 둘로 나뉘며 그 프로젝트 폴더에서 시작하는 터미널이 열립니다(프로젝트마다 셸이 따로 남고, 원격 프로젝트는 ssh로 접속한 원격 폴더, 구분선을 끌어 높이 조절). 코드는 색이 입혀지고, 마크다운·JSON·CSV 표·엑셀(xlsx)·이미지·PDF도 바로 볼 수 있습니다. 뷰어와 AI 채팅은 **Ctrl+마우스 휠**(또는 위쪽 줄의 확대·축소 막대)로 50~300% 키우고 줄일 수 있고, 마우스 커서가 있던 자리를 기준으로 커집니다. 이미지·엑셀·PDF는 확대한 뒤 **마우스 가운데 버튼(휠 클릭)을 누른 채 끌어서** 화면을 옮길 수 있습니다. Claude Code가 파일을 바꾸거나 새로 만들면 화면이 저절로 바뀝니다.

- **채팅 알림음**: 프로젝트 채팅이나 일반 채팅이 답을 끝내면 짧은 알림음이 울립니다(오류로 끝난 경우 포함, 직접 멈춘 경우는 제외). 옵션 탭의 "채팅이 끝나면 알림음"을 켜면 **채팅**·**프로젝트** 두 탭이 나타나, 각각 알림음을 켜고 끄고 음량을 조절하고 **미리 듣기**로 소리를 확인할 수 있습니다. 스위치를 끄면 알림음이 나지 않습니다.

### 화면 조절
- **전체화면**: 오른쪽 위 버튼이나 **F11**로 제목 표시줄·작업표시줄까지 가리고 전체화면으로 전환합니다(Esc로 종료).
- **사용량**: 오른쪽 위에 구독 플랜과 5시간 세션·주간 한도의 남은 %가 막대로 표시되고, 막대 옆에 초기화까지 남은 시간과 시각이 바로 보입니다. Claude Code를 실행할 때마다 갱신되고, 새로고침 버튼으로 바로 확인할 수도 있습니다.
- **탭 이동**: 메모리·대시보드에 갔다 와도 프로젝트 화면(열어 둔 파일, 입력 중인 글, 진행 중인 작업)이 그대로 유지됩니다. 사이드바의 "프로젝트"는 보던 프로젝트로 돌아가고, 목록은 프로젝트 화면 왼쪽 위 ← 버튼으로 갑니다.
- **사이드바**: 아래쪽 버튼이나 **Ctrl+B**로 접고 펼칩니다. 같은 자리에서 다크·라이트 모드를 바꿉니다.
- **패널 너비**: 탐색기 · 뷰어 · 채팅 사이 경계선을 드래그합니다(더블클릭하면 기본 너비). 비율은 자동 저장되어 재시작해도 유지됩니다.
- **패널 접기**: 탐색기와 뷰어는 각각 위쪽 버튼으로 접어 채팅을 넓게 쓸 수 있습니다. 얇은 막대를 누르면 다시 펼쳐지고, 접힌 뷰어는 파일을 열면 저절로 펴집니다.

### 3. 공통 메모리 (선택)
**메모리** 화면에서 개인 취향·대화 방식·피드백을 분류마다 하나의 목록으로 관리하면 모든 프로젝트의 대화에 자동으로 반영됩니다. 분류마다 2,000자 안으로 유지하도록 하나의 목록에 한 줄씩만 덧붙이고, 한 분류라도 넘으면 "메모리 압축"을 권합니다. 압축은 최근 대화에서 내가 좋아한 방식은 강화하고 고치라고 한 방식은 피하도록 목록을 다시 정리합니다(기술 스택·코딩 스타일은 제외). 코드를 어떻게 작성할지는 에이전트가 판단하므로 저장하지 않습니다.

- **자동 학습**: 대화 중 드러난 취향·반복된 피드백을 자동으로 메모리에 반영합니다. 그 분류의 목록에 한 줄씩 덧붙습니다. 메모리 화면의 **대화 기록에서 학습**으로 지금까지의 대화를 한 번에 분석할 수도 있습니다. 목록이 길어지면 **메모리 압축**이 나타나 초안을 보여 주고, 확인한 뒤 적용하면 핵심만 남깁니다(적용 직전 내용은 이 PC에 백업).
- **여러 PC 동기화**: Google Drive를 PC 폴더로 연결한 뒤(Windows: Google Drive for desktop), 메모리 화면에서 Drive 폴더를 선택하면 PC 간 메모리와 테마, 음악 목록, 홈 위젯이 자동 동기화됩니다(위젯은 하나씩 마지막으로 바꾼 쪽이 적용되고, 지운 위젯은 다른 PC에서도 지워집니다).
- **Claude Code 전역 연동**: 원하면 `~/.claude/CLAUDE.md`에도 메모리를 내보내 AIWorkspace 밖에서 Claude Code를 쓸 때도 참고하게 할 수 있습니다.

### 4. 대시보드
프로젝트의 Git 상태(브랜치·변경 사항·최근 커밋)와 Claude Code 설치 상태를 확인합니다.

### 5. 일반 채팅 (선택)
사이드바 **채팅**에서 프로젝트와 상관없이 Claude나 ChatGPT와 대화합니다. 입력창 위에서 모델을 고르고, 최신 정보가 필요한 질문은 **웹 검색**으로 조사해 출처 링크와 함께 답합니다(입력창의 웹 검색 버튼으로 끌 수 있습니다). 이미지·PDF·텍스트 파일(최대 5개)을 첨부해 질문할 수 있고, 대화는 앞 내용을 기억하며 이어집니다.
- Claude는 Claude Code에, ChatGPT는 Codex(`npm install -g @openai/codex`)에 로그인되어 있어야 합니다. 앱은 API 키를 저장하지 않고 이 프로그램들을 대신 실행합니다.
- 대화 기록과 첨부 파일은 이 PC에만 저장되며 대화를 삭제하면 함께 지워집니다. 메모리 탭의 공통 메모리(취향·말투)는 채팅에도 전달됩니다.
- 대화가 길어지면 알려 주고, **새 세션으로 이어 가기**로 최근 대화를 가져가 새로 시작할 수 있습니다.

### 6. 홈 화면 (선택)
사이드바 맨 위 **홈**은 AIWorkspace 작업과 무관하게 보고 싶은 정보를 모아 보는 화면이며, 처음에는 위젯이 하나도 없습니다. 위쪽 입력창에 원하는 위젯을 말하면(예: "오늘 할 일 목록", "크리스마스 D-day", "서울 날씨", "현재 시각", "미국 소비자물가·기준금리 그래프") 앱의 Claude가 위젯을 만들어 미리 보여 주고, 마음에 들면 추가 아이콘을 눌러 홈에 붙입니다. 위젯 카드의 연필 아이콘으로 수정을 요청하고 휴지통 아이콘으로 지울 수 있습니다. 날씨·환율·RSS처럼 외부 자료가 필요한 위젯은 키가 필요 없는 공개 주소의 자료만 쓸 수 있고, 받는 순간 이 PC의 IP가 그 서버에 보입니다. 위젯을 만들 때는 이 PC에 로그인된 Claude Code를 사용합니다.

### 7. 음악 듣기 (선택)
사이드바 **음악**에서 유튜브 링크를 붙여넣고 **추가**하면 음원을 내려받아 이 PC에서 재생합니다. 셔플 이어 재생(기본, 목록을 무작위 순서로 이어서 재생)·한 곡 반복·반복 끄기를 고를 수 있고, 다른 화면으로 옮겨도 계속 재생됩니다. 곡마다 있는 **활성/비활성 스위치**를 끄면 그 곡은 셔플·다음 곡 넘김에서 빠집니다(직접 눌러 재생하는 것은 가능).
처음에는 음원을 내려받는 도구(yt-dlp)가 필요합니다. 안내 상자의 **yt-dlp 내려받기**를 누르면 공식 배포처에서 받아 둡니다. 음원 파일은 이 PC에만 저장되고, 곡 목록(링크·곡별 음량)은 Google Drive 동기화 폴더를 설정했다면 다른 PC에도 같이 나타납니다(다른 PC에서는 재생할 때 음원을 받습니다). 곡마다 음량 슬라이더가 있습니다.

## 소스에서 직접 빌드하기

필요 도구: [Node.js](https://nodejs.org/) 24 이상, Rust(stable)
- Windows: Visual Studio 2022 Build Tools(C++), WebView2 Runtime
  ```powershell
  winget install Rustlang.Rustup
  winget install Microsoft.VisualStudio.2022.BuildTools --override "--quiet --wait --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
  ```
- Linux (Ubuntu·Debian):
  ```bash
  sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
  ```

```bash
git clone https://github.com/Miso-Nomika/AIWorkspace.git
cd AIWorkspace
npm install
npm run desktop:dev           # 개발 모드로 실행
npm run desktop:build         # Windows 설치 파일 (업데이트 서명용 비밀 키가 필요: 환경 변수 TAURI_SIGNING_PRIVATE_KEY, 평소에는 GitHub Actions가 빌드) → src-tauri/target/release/bundle/nsis/
npm run desktop:build:linux   # Linux .deb → src-tauri/target/release/bundle/
```

### 배포 (GitHub Actions)
- 검사는 모두 로컬에서 합니다(검사 코드는 저장소에 올리지 않습니다). 저장소에는 빌드·실행에 필요한 파일만 있습니다.
- 버전을 올리고(`package.json`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`) `v<버전>` 태그를 push하면 Windows(.exe)·Linux(.deb) 설치 파일이 빌드되어 릴리즈 초안에 첨부됩니다. GitHub에서 확인 후 게시합니다 (`.github/workflows/release.yml`). GitHub 용량·호출을 아끼려고 캐시와 수동 실행은 쓰지 않아 빌드 시간이 조금 깁니다.
